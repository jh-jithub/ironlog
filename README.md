# Ironlog

개인용 운동 기록 PWA. 상체/하체 2분할 기본 루틴, 루틴 추가/편집, 세트별 중량/횟수 기록, 운동 이력, JSON 백업/복원.

## 실행
HTTPS 정적 호스팅에서 ironlog 폴더를 서비스하세요. Safari > 공유 > 홈 화면에 추가.

## 저장
기록은 해당 브라우저의 localStorage에만 저장됩니다. 기기 변경/데이터 삭제에 대비해 설정에서 JSON 백업을 주기적으로 내보내세요. 별도 사용자 인증이나 서버 저장 기능은 없습니다.

## 주의
GitHub 저장소가 private이라고 해도 GitHub Pages로 공개 배포하면 앱의 정적 소스는 공개될 수 있습니다. 운동 기록은 기기에만 남지만 웹페이지 자체의 접근을 제한하려면 별도 인증 호스팅이 필요합니다.
